# Breakout scan

Daily and weekly scan for two patterns:

- ascending and descending triangles (one side horizontal, still forming)
- horizontal support or resistance with at least two touches, price back on the level

The page is published by GitHub Actions after the US cash close. The full US list is about 7,200 names and finishes later than the first update.

Triangle shape test is from [BennyThadikaran/stock-pattern](https://github.com/BennyThadikaran/stock-pattern) (GPL-3.0).
